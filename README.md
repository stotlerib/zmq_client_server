# Взаимодействие приложений C и Erlang через ZeroMQ (PUB/SUB) с использованием Chumak

Реализация тестового задания по организации взаимодействия (IPC) между сервером на языке **C (Publisher)** и клиентом на **Erlang (Subscriber)** через **ZeroMQ** с использованием библиотеки **Chumak**.

## Особенности архитектуры
По условиям задания сокет должен работать по протоколу `ipc` (или `inproc`). Однако Erlang-библиотека **Chumak** нативно поддерживает только протокол `tcp`.

Начиная с недавних версий Erlang/OTP, модуль gen_tcp поддерживает подключение к Unix-сокетам (IPC). Для этого вместо хоста передается кортеж {local, SocketPath}. Однако в оригинальном репозитории Сhumak ограничивает передачу хоста в функции connect, которые строго проверяют, что хост является списком (is_list/1). Из-за этого стандартная библиотека выбрасывает ошибку валидации при попытке передать кортеж.

Для обхода этого ограничения был сделан форк библиотеки Chumak, в котором была перегружена функция chumak_peer:connect/6. Новая сигнатура функции принимает строку SocketPath в качестве хоста и внутри трансформирует её в кортеж {local, SocketPath}, успешно устанавливая соединение.

## Зависимости

Для сборки и запуска проекта в операционной системе Linux (тестировалось на **Debian**) использовались:

*   `gcc` и утилита `make`
*   `libzmq`
*   **Erlang/OTP:** Версия 24 или выше
*   **Библиотека Chumak:** Версия 1.5.0
*   `rebar3`

---

## Сборка и запуск

Все этапы автоматизированы с помощью корневого `Makefile`.

### 1. Сборка
*   ```bash
    make
    ```

### 2. Запуск

*   ```bash
    make run_server
    ```

*   ```bash
    make run_client
    ```

### 3. Очистка

*   ```bash
    make clean
    ```

---

## Пример работы

1. После запуска сервера в консоли появится приглашение к вводу:
   ```text
   make run_server
   Server is running and bound to ipc:///tmp/zmq_client_server_0:
   Type 'send' to send the message
   send
   [Message sent] Current time: 2026-09-01 13:40:55
   ```
3. В консоли клиента отобразится полученное сообщение:
   ```text
   make run_client
   [Message received] Current time: 2026-09-01 13:40:55
   ```
