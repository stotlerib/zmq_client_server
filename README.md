# Взаимодействие приложений C и Erlang через ZeroMQ (PUB/SUB) с использованием Chumak

Реализация тестового задания по организации межпроцессного взаимодействия (IPC) между сервером на языке **C (Publisher)** и клиентом на **Erlang (Subscriber)** с использованием библиотеки **Chumak**.

## Особенности архитектуры
По условиям задания сокет должен работать по протоколу `ipc/inproc`. Однако Erlang-библиотека **Chumak** нативно поддерживает только протокол `tcp`. 

В качестве решения используется утилита `socat` в качестве моста между `ipc` и `tcp` протоколами. Альтернативным решением было бы изменение исходного кода библиотеки путем перегрузки метода `connect`.

**Схема работы:**
`[C Сервер (PUB)]` (ipc://) --> `[socat мост]` (tcp://) --> `[Erlang Клиент (SUB)]`

## Зависимости

Для сборки и запуска проекта в операционной системе Linux (тестировалось на **Debian**) использовались:

*   `gcc` и утилита `make`
*   `libzmq`
*   **Erlang/OTP:** Версия 24 или выше
*   **Библиотека Chumak:** Версия 1.5.0
*   `rebar3`
*   `socat`

---

## Сборка и запуск

Все этапы автоматизированы с помощью корневого `Makefile`.

### 1. Сборка
*   ```bash
    make
    ```

### 2. Запуск

*   ```bash
    make run_socat
    ```

*   ```bash
    make run_server
    ```

*   ```bash
    make run_client
    ```

### 3. Очистка

*   ```bash
    make clean
    ```

---

## Пример работы

1. После запуска всех компонентов в консоли **C-сервера** появится приглашение к вводу.
2. Введите команду `send` и нажмите Enter:
   ```text
   $ make run-server
   Введите команду 'send' для отправки времени: send
   [Отправлено] Текущее время: 2026-09-04 16:00:05
   ```
3. В консоли **Erlang-клиента** отобразится полученное сообщение:
   ```text
   \$ make run-client
   === Клиент Chumak SUB запущен и ожидает сообщений... ===
   [Получено сообщение]: "Текущее время: 2026-09-04 16:00:05"
   ```
